# TV Remote for Mac v0.2

Find your Samsung TVs on the local network and keep a named remote for each one.

## What's new

- **Find TVs:** discover responsive Samsung TVs using local IPv4 SSDP, with names, model information and IP addresses. Select a result to fill the setup form, then choose **Save & Connect**. Manual IP entry remains available.
- **Multiple remotes:** add, name, switch, rename and remove saved TVs. The TV-name menu above the controls switches remotes; IP addresses distinguish TVs with the same name.
- **Persistent setup:** saved remotes and the selected TV survive restarts. Existing v0.1 settings migrate automatically without discarding per-TV pairing credentials.
- **Safer setup flow:** discovery does not pair with a TV or send remote commands. Stopping a search or closing settings cancels it; canceled setup drafts never become active connection targets.
- **Device details:** handles real Samsung SSDP extension headers and escaped display names. A MAC address reported during discovery can be remembered after a successful connection for best-effort wake.

The compact, click-only menu-bar remote and its controls remain unchanged. No Dock icon, hover activation, account, ads, subscription or cloud service.

## Download and install

Download **TV-Remote-v0.2-arm64.dmg**, open it, and drag **Notch Remote.app** to Applications. If replacing an existing copy, quit it first. Open the app, click its menu-bar icon, open the gear, and choose **Find TVs** or enter an IP manually. Name the TV, choose **Save & Connect**, and approve the connection on the TV if asked.

Use **Add TV** for additional remotes. Removing a saved remote only removes its list entry; **Re-pair TV** explicitly clears pairing for the address in the form.

The DMG is for **Apple silicon Macs**, with a deployment target of **macOS 13+**. Not every OS or TV model has been physically tested. The app is **ad-hoc signed, not Apple-notarized**; macOS may require manual approval in Privacy & Security on first launch. `SHA256SUMS` is included for download verification.

No personal pairing credentials or device configuration are included. The bundle name and identifier remain unchanged for compatibility with existing installations.

## Compatibility and limits

- **Samsung only.** Requests for [any TV brand or model](https://github.com/momchilon/tv-remote-mac/issues/new?template=tv-support.yml) are welcome; support and delivery dates are not guaranteed.
- Turn the TV on and allow local-network access in macOS. Guest-network isolation, blocked multicast and VPN/firewall configuration can prevent discovery. Manual IP setup remains the fallback.
- Discovery metadata is unauthenticated; control still uses the existing per-TV pinned TLS connection. Discovery ignores advertised URLs, rejects HTTP redirects/authentication challenges, and limits response size and request duration.
- Wake remains best-effort and requires a valid MAC address plus working standby networking. Not all models report a MAC or support network wake.
- No app launcher, screen mirroring or non-Samsung control backend. A successful key write is not an acknowledgment that the TV performed it.

## Verification

The release was checked with headless app/profile tests, real loopback UDP/HTTP and TLS/WebSocket integration tests, bundle/signature validation, and a hidden read-only mount of the packaged DMG. Discovery was also exercised against physical Samsung devices. GUI automation suites remain opt-in and were not run as part of packaging.
