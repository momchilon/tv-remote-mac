# TV Remote for Mac v0.1

The first public, MIT-licensed release of a tiny native TV remote for the macOS menu bar.

## Samsung today — requests for any TV welcome

**v0.1 currently supports Samsung smart TVs only.** Compatibility depends on the model and firmware.

Want LG, Sony, Philips, TCL, Hisense, Roku, Android/Google TV, or another brand? [Request support for any TV brand/model](https://github.com/momchilon/tv-remote-mac/issues/new?template=tv-support.yml). Include the brand/model, approximate year or OS, desired controls, and whether you can test. Requests are welcome, but support and timing are not guaranteed. Please do not post pairing tokens or private network/device identifiers.

## What is included

- Click-only remote-shaped menu-bar icon; controls open directly beneath it.
- Direction pad/OK, volume, mute, Back, Home and input selection.
- Power-off confirmation and local Samsung pairing with per-TV TLS certificate pinning.
- No Dock icon, hover activation, ads, subscription, account or cloud backend.
- Full MIT-licensed source, build scripts, tests and GitHub issue templates.

## Download and install

Download **TV-Remote-v0.1-arm64.dmg**, open it, and drag **Notch Remote.app** to Applications. Open the app, click the remote icon, enter your TV's local IP address, and choose Allow on the TV. The original bundle name is retained for compatibility; the UI is a menu-bar popover, not a notch panel.

The DMG is for **Apple silicon Macs** with a deployment target of **macOS 13+**; not every OS/TV version has been tested. This build is **ad-hoc signed, not Apple-notarized**, so macOS may require manual approval on first launch. `SHA256SUMS` is provided for the DMG.

No personal pairing credentials or device configuration are included. Source ZIP/tar archives are available below from the v0.1 tag.

## Known limitations

Samsung only; manual IP setup; no TV discovery, app launcher or mirroring. Wake-on-LAN is best-effort, requires a known MAC/working standby network, and does not yet have MAC discovery/input in the public UI. UI tests are opt-in; default tests use no desktop automation and no real-TV key commands.
